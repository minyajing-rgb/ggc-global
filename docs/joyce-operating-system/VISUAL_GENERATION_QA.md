# Visual Generation QA — Mandatory Checklist

> Version: 2026-10-08  
> Applies to every future GGC deck / poster / PDF image generation.

# 1. Source-of-Truth Check

Before generating a page, confirm:

- [ ] page number and title match `CLOSED_DOOR_DECK_MASTER.md`
- [ ] key facts / numbers / product stages match the source
- [ ] historical result, current product, projection, and design concept are not mixed
- [ ] no new company / client / product claim is invented
- [ ] pricing uses the latest confirmed reference

# 2. Joyce Identity Check

- [ ] Joyce portrait appears at most once in a deck unless Joyce explicitly asks otherwise
- [ ] use the original photo directly
- [ ] no AI face redraw
- [ ] no cheekbone exaggeration
- [ ] no body proportion changes
- [ ] no identity-changing retouching

# 3. Visual Style Check

Approved direction:

- [ ] white / milk-white base
- [ ] bold black large type
- [ ] magenta → violet → blue gradient only for emphasis
- [ ] subtle iridescent / holographic glass accents
- [ ] 30–50% whitespace for hero / poster pages
- [ ] clean premium executive feel
- [ ] large hierarchy before small explanation
- [ ] handwritten accent used sparingly
- [ ] no full saturated pink content blocks
- [ ] no generic corporate-template / PPT-card feeling
- [ ] no cute cartoon treatment unless the product itself requires it

# 4. Information Density Check

Joyce's audience is senior.

Do not over-simplify into empty slogans.

A good page should contain one executive conclusion plus enough evidence to support it.

- [ ] headline = conclusion
- [ ] subhead = why it matters
- [ ] chart / case / product visual = evidence
- [ ] small text = scope / caveat / definition
- [ ] same-type content merged
- [ ] different evidence sets not merged

# 5. Numbers / Evidence Check

For every number ask:

- Is this:
  - [ ] historical project result
  - [ ] external partner / client result
  - [ ] self-owned product result
  - [ ] model prediction
  - [ ] research inventory
  - [ ] UI sample / design number
  - [ ] current snapshot

Then label it correctly.

Never:
- [ ] turn projection into actual
- [ ] turn research object into self-developed product
- [ ] turn asset count into product count
- [ ] turn UI placeholder into business performance
- [ ] turn historical result into GGC current company financials

# 6. Product Stage Check

Use explicit stage language:

- Research
- Design
- Prototype
- Partial implementation
- Historical test
- Published
- Commercial validation
- Blocked / pending verification

Never hide stage differences behind one completion percentage.

# 7. Public-Safe / Desensitization Check

Remove:
- client names without permission
- contact records / private chats
- personal family details
- internal account IDs
- passwords / secrets
- private URLs
- internal implementation paths
- exact proprietary thresholds unless approved

Keep:
- category
- problem
- role
- sanitized result
- operating lesson
- reusable framework

# 8. Page Acceptance Test

Reject the output if any answer is "no":

1. Does it look like the approved Joyce / GGC visual system?
2. Does it say something a founder / CEO / VP cares about?
3. Is the conclusion immediately legible?
4. Is there enough evidence behind the conclusion?
5. Are facts and stages accurate?
6. Is Joyce positioned as industry insight expert / strategic operator, not cheap service provider?
7. Does the page make the next conversation easier?

# 9. Deck-Level Final QA

Before exporting PDF:

- [ ] portrait count = approved
- [ ] book page included
- [ ] all locked pages present
- [ ] no duplicated argument pages
- [ ] early deck establishes credibility
- [ ] middle deck proves operating depth
- [ ] current work is concrete
- [ ] vision is one coherent page / section
- [ ] collaboration and pricing are clear
- [ ] contact / CTA page is final
- [ ] no temporary review comments appear in final PDF
