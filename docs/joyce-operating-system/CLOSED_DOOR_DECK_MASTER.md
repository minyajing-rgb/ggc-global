# Non-Negotiable Visual Rules

1. White / milk-white background.
2. 30–50% whitespace on poster-like pages.
3. Black bold headline + restrained magenta / violet / blue gradient accents.
4. Holographic / iridescent decoration = accent, not background clutter.
5. Joyce real photo appears **at most once** in the deck.
6. Never AI-redraw Joyce's face for the deck.
7. Avoid full pink blocks.
8. Avoid generic PowerPoint service-card look.
9. Use real product / report / dashboard images where possible.
10. One slide = one executive conclusion.
11. Dense information is acceptable if hierarchy is strong.
12. Every numeric claim must retain scope / period / evidence type.
