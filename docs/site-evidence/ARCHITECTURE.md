# Architecture
Canonical content: docs/site-evidence/public_content.py. Renderer emits escaped strings and native details HTML. Biz incremental update script calls apply_biz on the existing approved HTML; legacy full rebuild is not triggered. Corporate build_ready calls apply_corporate after readiness/public-facts preparation; hash-protected old source/assets unmodified. Corporate PR11 contains same renderer copy to keep release reproducible. Changes limited to named page bodies and one scoped asset; metadata/forms unchanged.
No new service, auth, persistence or analytics. Release: commit to original biz main; corporate PR11 commit passed as source_ref to existing corporate manual publish. Preserve recovery commits and use ordinary non-forced Git writes. No DNS/billing/permission changes.
