## 后续每批怎么对照

```bash
cd docs/weekly-os/closed-door-deck
python verify.py
python verify.py --prepare 01-10 --commit "$(git rev-parse HEAD)"
# 第二批和第三批分别使用11-20、21-29。
```

批次输入会从母稿提取完整对应页，输出Sxx.md、input.md与未勾选的qa.json。生成后逐页核对标题/正文、数字/单位/限定、风格、遮挡裁字、肖像书封和脱敏情况。失败页重新制作；未检查不能记通过。程序只校验源文、文件、尺寸与验收记录，不宣称自动读懂图片。

图片统一命名为 `images/S01.png` 至 `images/S29.png`；通过检查的29张独立图再一图一页拼成PDF。必须使用本目录规范，不能继承父目录旧Weekly OS模板中“封底可用人像”等过时规则。
