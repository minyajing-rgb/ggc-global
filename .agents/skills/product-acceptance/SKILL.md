Read product-definition and full approved PRD/mockups/flows/architecture. Freeze exact repo/commit/build/URL/environment/time/browser/device/locale/width. Use all concrete pages/dynamic instances/nested branches/tabs/modals/controls/states as denominator; compare actual router and visible links. PASS/FAIL/BLOCKED/NA_WITH_REASON, untested BLOCKED; report covered/total.
PAGE_REVIEW_CARD per page: requirement/flow/mockup IDs; expected vs actual; real desktop/mobile reference pairs; truthful content/source/locale/imagery; every control's destination/side effect; all states; accessibility; console/network/private access/metadata; evidence commit/defect IDs. Open pixels beside approved mockups: hierarchy/spacing/type/contrast, images/cropping/readability, overlap/clipping/long text/sticky bars, unique names/keyboard/focus return/zoom/touch/reduced motion. Capturing screenshots, DOM tests, HTTP200 or builder claims are not visual acceptance. Previews are not restored high-resolution originals; emulated widths are not physical-device QA.
Exercise positive/alternative/failure: empty/invalid/long input, loading/success/no-results/error/timeout/offline/retry, denied storage/permissions, guest/auth, cancel/back/refresh/deeplink/repeated actions. Observe real state/network and applicable auth/RLS/data/model/forms/payment with safe test data; no unauthorized charge/send/private writes or weakened security. Check visitor value, architecture/privacy/full locales/SEO/measured performance.
DEFECTS.json records severity/page/state/requirement, reproduction, expected/actual, evidence, owner, fixing commit and RETEST plus regressions. P0 security/data-loss; P1 missing/broken required path or essential visual evidence/misleading success; P2 nonblocking quality. Fix/retest; untested fix stays open. Gate B implemented+built. Gate C INTERNALLY_ACCEPTED only complete coverage+actual pixel inspection+zero open P0/P1+explicit P2 exceptions. Otherwise NOT_READY with exact gaps; no scope waiver.
Gate D LIVE_VERIFIED only after authorized release: actual domains, redirects/body/title/asset hashes vs tested build; all live routes/locales/critical flows, console/network/SEO/canonical/lang/OG and auth/rollback. SPA200 can serve wrong page. Missing candidate NOT_DEPLOYED. Preview/rebuilt production need separate tests. Never publish or redo backups just to satisfy a check.
Reuse evidence only if diff proves page AND shared data/styles/translations unchanged; unknown mappings fail closed. Label method/version. Deliver only self-checked candidate with actual previews, coverage, defects/build, no repeated review reminders. Templates in pinned canonical .agents/skills. COPIED, ACTIVATION_TESTED, AUTOMATION_RUNNING are distinct; repository files alone do not activate global execution.
