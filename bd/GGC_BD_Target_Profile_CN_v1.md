# GGC BD目标画像 · 国内华人团队版 v1.0（LOCKED 2026-09-18 Joyce确认）
> 双引擎体系下B池新增的核心子画像：缺角的中文自研团队。年框Operating Partner填的正是他们缺的那一角。

## 一、四类目标团队（讲中文优先，国内定向扫）
1. **国内自研 → 想出海**：国内有稳定营收，缺全球化操作系统（市场排序/UA经济/本地化/LiveOps节奏）
2. **海外定制外包 → 转自研自发**：有海外交付能力，缺自有产品和长线运营经验
3. **纯研发 → 想自建发行**：明确不想找外部发行合作，想自己搭发行团队——缺的正是发行/运营架构能力，GGC以External Operating Partner身份补角（不是发行合作，是帮他们把发行团队和运营体系建起来）
4. **集团型研发团队**：几家分公司在一起的，有体量有产品线，缺统一出海战略的

## 二、硬条件
- 年营收 **几千万RMB到上亿+**（对应月流水约¥300万-¥1000万+量级）
- 讲中文优先（国内扫，含华人出海团队）
- 有自研产品（不是纯CP外包没产品的）

## 三、为什么这个画像精准命中GGC
缺角团队不要发行合作、要自己搭——传统发行商接不了这个单（发行商要的是代理权）。GGC的COPILOT/年框模式恰好是"帮你自己建体系"：不拿代理权，收服务费+增量分成，把他们的发行团队、数据体系、LiveOps架构建起来。这批人付得起年框（年营收几千万起），又是决策链最短的（老板拍板）。

## 四、扫描源（每日新增维度）
1. App Store CN免费/畅销榜 + 微信小游戏畅销榜（国内体量信号）
2. 海外榜单上的华人/中国团队（ Hungry Studio、GAME SPARK、Just Game HK、Vita Studio、BILIBILI HK这类——出海带子产品的）
3. 白鲸出海/扬帆出海/游戏葡萄/gamelook 融资与新品新闻（年营收几千万级的团队不上美国榜，从新闻扫）
4. 点点数据中国厂商出海收入榜（腰部段位=画像命中区）
5. 外包转自研的行业访谈线索
