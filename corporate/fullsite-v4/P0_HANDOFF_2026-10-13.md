## Use the new build entry point

The accepted build and its hash-protected files remain unchanged. `build_ready.py` builds them in an isolated temporary directory, then applies the P0 additions. **The old `prepare_site.py` alone is the baseline visual build, not the P0-ready artifact.**

```sh
# Default: safe preview. BASE_URL is a canonical target chosen by Codex, not a DNS operation.
python corporate/fullsite-v4/build_ready.py \
  --out /tmp/ggc-pr11-preview \
  --base-url https://ggcgames.com/

# Release artifact only. Does NOT deploy, enable hosting or claim the site is live.
python corporate/fullsite-v4/build_ready.py \
  --out /tmp/ggc-pr11-release \
  --mode release \
  --base-url https://ggcgames.com/
```

The base URL is required, validated, and supports a subdirectory. Codex must substitute the confirmed canonical host/path if it differs. Output must be new/empty; no existing build or site is silently overwritten. No font files are copied or committed.

No fake Article dates, ratings, customers or revenue claims.

- Release sitemap contains **94 canonical URLs**: the 98 locale pages minus 2 component-library pages and 2 404 pages. Review hub and root redirect are not included. No fabricated `lastmod` timestamps.
- Preview pages remain `noindex,nofollow`; preview sitemap is empty and unadvertised. Release pages intended for indexing use `index,follow`; component/review/404 pages stay noindex. `robots.txt` allows crawlers to read these directives. It is not access control.

- Release removes the internal all-screen review link and collapsible future subscription-state simulator from public visitor flows. Preview retains those review aids. Existing explanatory method/product labels remain untouched.

## Keyboard and form safety

The added `readiness.js` runs before the unchanged legacy scripts and installs a no-navigation submission guard. Named controls are restored only after that guard exists; initial submit actions are disabled. With JavaScript unavailable, forms remain unnamed/disabled and offer a direct email alternative, avoiding a native GET fallback that could put personal fields in the URL.

Mobile navigation stays a non-modal disclosure: Enter/Space opens it; Tab enters links; Shift+Tab returns to its trigger; Escape closes with focus return. Galleries retain native button tab stops, gain descriptive localized labels/controlled slides and optional arrow keys. The skip link has a programmatically focusable main destination. Existing selected tabs, filters and search continue to work.

Prepared email links are invalidated if input changes. Locale switches allow only valid S01–S16 and recognized partnership-track values, not arbitrary referral content. Contact and updates notices explain **local draft → user reviews/sends in mail app**; no automatic request, CRM record, active mailing list, confirmation or unsubscribe is claimed.
