# GGC — Product Review、上线 Checklist 与性能门禁

日期：2026-10-13。检查基线：PR #11 / `bfcfc489463440afa44a2ee39b822de4545524ec`，原分支 `feature/ggc-corporate-rebuild-20261010`。

范围：源码、生成产物、产品评审与 CI。Codex 继续负责正式托管、DNS、HTTPS、发布和线上验收。本轮不发布、不启用表单、不接入统计、不改变任何托管设置。

## 一、产品结论：页面齐全，不等于业务闭环齐全

当前源码保留已确认的16类UI、原96个中英文页面，以及新增的两页隐私说明。结构、字体选择、六款按钮、配色、肖像和书封不因性能优化而重做。

需要区分四种完成状态：

1. **公司介绍站**：已有通过源码验证的产物。PR记录 Codex 已发布较早的固定 source SHA，并检查98个语言页面；这不是本轮再次完成的线上验收。
2. **在线商务询单**：默认依旧是由访客自行发送的邮件草稿。较新源码带有必须明确启用的 FormSubmit 候选方案。两个语言来源的激活和实际收信仍须验收；mock成功不等于收到邮件。
3. **商业说服力**：研究主题页、产品说明画廊的标注是诚实的，但不等于原始报告、可核验案例或真实产品截图。这是页面覆盖之后最重要的转化质量缺口。
4. **自动化经营**：CRM、自动订阅、双重确认、退订与生产漏斗监测都未接通，不以页面或代码存在代替业务完成。

### 评审依据

用户提供的《Joyce Method》四页稿第2页，强调 Decide / Build / Compound，以及 Diagnose → Prioritize → Build → Operate → Review → Scale/Stop → Codify。《九张原始海报》第7页强调服务、研究、知识、消费产品和孵化之间相互增强。以上是用户的目标与方法，不是功能已经完成的证据。下列验收项是据此提出的运营与工程标准，不改写原方法。

## 三、本轮性能改动

`build_fast.py`先调用现有`build_ready.py`，再运行保守的标准库后处理；这是同一网站的构建层，不是另一套设计或新托管项目。

- **CSS**：按原级联顺序合并6份本地样式，仅移除注释，不改变选择器和值中的空白，生成内容哈希文件。原始样式文件保持原字节。
- **JavaScript**：按原顺序合并3份经典defer脚本，确保提交保护先于应用处理器。遇到意外async/module/currentScript等语义直接拒绝，不猜测调整。在线询单仍沿用原显式开关。
- **字体**：把现有Google Fonts样式从嵌套CSS `@import`提前到HTML，增加preconnect；完整保留字体族、字重和`display=swap`，不打包字体文件。第三方字体的地区可达性仍待线上测量。
- **图片**：补齐肖像400×421、书封350×466真实尺寸与async解码。About／Book明确的首屏图采用eager/high；首页下方肖像采用lazy。已有小体积WebP不重新压缩、不换人像。书封保留原max-height下的auto尺寸，避免添加尺寸属性改变外框比例。
- **稳定性**：SEO、sitemap／robots、内外链、隐私及询单模式、原始素材哈希保持；空标题只调整可访问语义，不变外观。

### 实测源文件体积，不冒充加载速度

| 项目 | 原产物 | 优化候选 | 含义 |
|---|---:|---:|---|
| 本地CSS请求 | 6 | 1 | 保持同样级联顺序 |
| 本地defer JS请求 | 3 | 1 | 保持同样执行顺序 |
| CSS gzip-9估算 | 21,734 B | 17,096 B | 同等级gzip下约减少21.3% |
| JS gzip-9估算 | 4,757 B | 3,879 B | 同等级gzip下约减少18.5% |
| CSS＋JS gzip-9估算 | 26,491 B | 20,975 B | 约减少20.8%；不含HTML、图片、字体、请求头和TLS |
| 字体发现链 | HTML→本地CSS→字体CSS | HTML→字体CSS | 减少发现依赖，不保证字体服务商延迟 |

这些是可复算的构建数据，不是“网站快了20.8%”。CI记录实际产物、像素／几何对比和受控实验样本。为可重复性，实验中的外部字体CSS被替代为空响应，所以不包含真实Google字体传输和延迟，不据此宣布真实INP或p75通过。

## 五、构建交接

```sh
# 默认仍是预览noindex；使用新建或空目录。
python corporate/fullsite-v4/build_fast.py \
  --out /tmp/ggc-fast-preview \
  --base-url https://ggcgames.com/

# 只生成正式候选，不发布，也不启用在线询单。
python corporate/fullsite-v4/build_fast.py \
  --out /tmp/ggc-fast-release \
  --mode release \
  --base-url https://ggcgames.com/
```

不要仅因代码支持就添加`--inquiry-endpoint`。现有开关、邮箱激活和真实送达验收由Codex及运营者决定，本轮优化不启用它。

读取`performance-evidence/review.json`及候选站点的`performance-manifest.json`。原P0与全站workflow保持不变并继续要求通过；新workflow只有contents read权限，仅上传产物，不改变Netlify／Bolt／Base44／GitHub Pages、DNS、HTTPS或生产仓库。
