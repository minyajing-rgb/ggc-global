# Joyce / GGC — Media & Speaking Outreach Playbook

Version: 2026-10-03-v2

## Objective

Build durable relationships with editors, reporters, podcast / newsletter hosts and conference content teams so Joyce becomes a reusable expert source and speaker, not a one-off self-promotional pitch.

## Two separate pipelines

### Media

`Seed → Route + Format Qualified → Contacted → Human Editorial Interest → Quote / Briefing / Interview / Commission → Publication → Repeat Source → Inbound Business Conversation`

Side states: `Human Decline / Format Mismatch`, `Auto Routing Only`, `Bounce`, `No Human Response`, and `Paid / Commercial Route`. These are not forward progression. An interview is one possible format, not a required step for every outlet.

### Speaking

`Qualified Event → Content Team Contact → Proposal → Shortlist → Accepted → Panel / Fireside / Solo → Featured / Keynote → Repeat Invite`

Do not merge “submitted” with “accepted”.

## Route and format gate before drafting or following up

Use [PR_TARGET_GRAPH.csv](PR_TARGET_GRAPH.csv) together with [Media Route Feedback](MEDIA_ROUTE_FEEDBACK.md). Priority A, a verified organization, a public email or a matching topic does not establish format fit.

For each proposed touch, record:
1. the outlet, specific desk / host / producer and audience;
2. one route: independent editorial, podcast, contributor, research / vendor content, event programming, paid PR or commercial partnership;
3. one selected format: news tip, quote, reported trend story, company profile, commissioned interview, podcast guest, contributed article or speaker proposal;
4. an official format guideline or comparable recent coverage URL, with the date checked; a homepage or advertising page alone is insufficient proof of interview acceptance;
5. the outlet-specific hook, two evidence points, why now and the requested deliverable;
6. current feedback, format suppression and same-outlet contact state.

An unverified route or format stays in research / qualification. Explicit editor feedback takes precedence over inferred fit from articles. Check suppression at outlet + format level across contacts and hooks; do not bypass it by changing subject lines, titles, recipients or mailbox.

## Reply classification and follow-up rules

Classify only the newly authored reply, excluding quoted original pitches and signatures. Check automation headers first (`Auto-Submitted` other than `no`), then sender / body signals; uncertain cases remain unclassified for review.

| Reply class | Human reply KPI | Positive editorial reply KPI | Follow-up policy |
|---|---:|---:|---|
| `HUMAN_EDITORIAL_INTEREST` | Yes | Yes, only if a person substantively requests evidence, a quote, an interview, a commission or editorial discussion about this story | Respond to the requested next step |
| `HUMAN_FORMAT_REJECTION` | Yes | No | Close current pitch; suppress materially similar outlet-format pitches; no timed retry or contact substitution |
| `HUMAN_DECLINE` / opt-out | Yes | No | Stop rejected pitch; honor broader opt-out scope where stated |
| `AUTO_ROUTING_ONLY` / auto acknowledgement / out-of-office | No | No | Save routing facts only; no interest score, warm-lead upgrade or auto-triggered follow-up |
| Paid PR / sponsorship / marketing offer | Only if human-authored | No | Commercial lane only; spending needs separate explicit authorization |
| `NO_HUMAN_RESPONSE` / bounce | No | No | Do not infer interest; bounce blocks reuse of the failed address |

Reconcile message identity in the private ledger so an auto-reply and a later human reply are not counted twice. One generic routing form or boilerplate instruction to submit is not a substantive editorial request. Human negative feedback remains a reply for diagnostics, never a positive result.

No automatic bulk outreach or follow-up is enabled. Every future follow-up must satisfy the route / format gate, contain new material value and be within the user's messaging authorization; a relationship sequence is not a mandatory resend schedule.

## Relationship sequence

### Touch 1 — Give value
Reference the person's current beat / event theme and offer one concrete observation, anonymized case pattern or data point. No ask for coverage.

### Touch 2 — Make quoting easy
Offer 2–3 concise, evidence-bound points that can be used as expert commentary.

### Touch 3 — Offer early access
For a GGC research report / framework, offer a preview or embargoed briefing to a small number of relevant editors / producers.

### Touch 4 — Interview / stage proposal
Only after the exact outlet format is established, propose its supported deliverable. Offer a 20–30 minute interview only where that format is supported; use a quote, story evidence memo, podcast proposal or talk abstract when appropriate.

## Event producer targets

Prioritize:
- Conference Producer
- Content Director
- Program Director
- Head of Content
- Speaker / Programming Manager

Sponsorship sales is not the default route for editorial speaking opportunities.

## Pitch anatomy

1. **Why now** — one current industry trigger.
2. **Why this audience** — what their readers / attendees are trying to decide.
3. **Joyce's evidence** — only the minimum relevant proof.
4. **The idea** — one sharp thesis.
5. **What they get** — data / framework / examples / takeaways.
6. **Low-friction next step** — short briefing, quote or talk abstract.

## Operating cadence

Weekly minimum:
- one evidence-led media pitch;
- one event / producer pitch;
- one relationship follow-up with new value;
- one long-form or research asset advanced;
- one reusable short-form asset published.

Monthly:
- one major point-of-view package that can support media, speaking and owned distribution.

## Public / private data rule

This public repository contains templates and strategy only. **Do not commit target contact details, private email addresses, private replies, organizer negotiation terms or outreach CRM data here.**

Those records belong in an authorized private business workspace.

## Qualification before paying to speak / travel

Evaluate:
- audience relevance;
- speaker format;
- official speaker page and organizer distribution;
- recording / photography;
- attendee decision-maker density;
- business meetings that can be scheduled around the event;
- travel support;
- long-lived asset value.

A paid / self-funded appearance should not be justified by a logo wall alone.

## Distribution cascade for one strong idea

Research / point of view  
→ priority editor / producer preview  
→ interview / publication / stage  
→ GGC site  
→ LinkedIn / owned channels  
→ short video / quote cards  
→ follow-up briefing  
→ executive conversations

The same evidence base can be reused; the angle should be tailored to each audience rather than mass-sent unchanged.
